# ✅ Интуитивный интерфейс управления количеством постов - РЕАЛИЗОВАНО

## 🎯 Выполненная задача

**Заменили техническую настройку "порог виральности" на интуитивный ползунок**, который показывает SMM-менеджеру понятную информацию: **сколько постов в неделю** будет присылаться из источника.

---

## ✅ Что реализовано

### 1. **Backend (API + Database)**
- ✅ Создан endpoint `/api/vk-sources/:id/percentile-stats`
  - Возвращает статистику по 11 перцентилям (p50-p97)
  - Показывает примерное количество постов/неделю для каждого
  - Основано на реальных данных за последние 7 дней
  
- ✅ Добавлено поле `customPercentile` в модель VkSource
  - Диапазон: 50-99
  - Дефолт: 90 (топ-10% постов)
  
- ✅ Автоматический пересчёт порога при изменении перцентиля
  - При сохранении нового значения → сразу пересчитывается threshold
  - Использует `vkService.updateSourceThreshold()`

### 2. **Frontend (React Component)**
- ✅ Создан компонент `PercentileSlider.js`
  - Material-UI Slider (50-97)
  - Понятные метки: "Больше", "Много", "Средне", "Выборочно", "Меньше"
  - Цветовые индикаторы (красный → оранжевый → синий → зелёный)
  
- ✅ Интегрирован в `SourceForm.js`
  - Заменил старые настройки порога
  - Автоматически загружает статистику
  - Показывает текущее и новое значение
  
- ✅ Real-time preview
  - ~X постов в неделю
  - Порог виральности (просмотры)
  - Процент топ-постов
  - Сравнение: "больше/меньше чем сейчас"

### 3. **UX Improvements**
- ✅ Понятные метки вместо перцентилей
- ✅ Визуальный feedback (цвета, иконки)
- ✅ Loading/Error states
- ✅ Интерполяция между точками данных
- ✅ Адаптивный дизайн
