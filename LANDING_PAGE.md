# Посадочная Страница и Структура Приложения

## Обзор

Добавлена посадочная страница (Landing Page) для рекламы сервиса FeedRank. Текущий функционал перенесен в личный кабинет.

## Структура URL

### Публичные страницы
- **`/`** - Посадочная страница (Landing Page)
- **`/login`** - Страница входа
- **`/register`** - Страница регистрации

### Личный кабинет (защищено авторизацией)
- **`/app`** - Dashboard (главная страница личного кабинета)
- **`/app/sources`** - Список источников контента
- **`/app/source-groups`** - Группы источников
- **`/app/channels`** - Telegram каналы
- **`/app/mappings`** - Маппинги источников на каналы
- **`/app/analytics`** - Аналитика
- **`/app/settings`** - Настройки

## Компоненты

### LandingPage
Расположение: `/client/src/components/landing/LandingPage.js`

Современная посадочная страница с:
- **Hero секция** с призывом к действию
- **Статистика** - ключевые цифры сервиса
- **Возможности** - 6 основных функций платформы
- **Как это работает** - 3-шаговое объяснение процесса
- **Call-to-Action** - приглашение начать использовать сервис
- **Навигация** - кнопки для входа и регистрации

### Особенности дизайна:
- Градиентный фон (фиолетовый)
- Анимации при наведении на карточки
- Адаптивный дизайн (responsive)
- Material-UI компоненты
- Иконки для визуального представления функций

## Изменения в роутинге

### App.js
- Добавлен маршрут `/` для LandingPage
- Все защищенные маршруты перенесены под `/app`
- Неизвестные маршруты перенаправляются на `/`

### Layout.js
- Обновлены пути навигации с относительных на абсолютные `/app/*`
- Сохранена вся функциональность бокового меню

### Auth компоненты
- `Login.js` и `Register.js` перенаправляют после авторизации на `/app`
- `PrivateRoute.js` перенаправляет неавторизованных на `/login`

## Преимущества новой структуры

1. **Маркетинг** - Посадочная страница для привлечения новых пользователей
2. **SEO** - Публичная страница для поисковой оптимизации
3. **Разделение** - Четкое разделение публичной части и личного кабинета
4. **UX** - Понятная навигация для новых и существующих пользователей

## Запуск

```bash
cd client
npm start
```

Приложение будет доступно по адресу: http://localhost:3000

- **http://localhost:3000/** - Посадочная страница
- **http://localhost:3000/app** - Личный кабинет (требует авторизации)
