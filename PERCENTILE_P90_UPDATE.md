# Обновление перцентиля с p85 до p90

## 📊 Изменения

### Дефолтный перцентиль изменён с **p85 на p90**

**Что это означает:**
- **p85**: Порог устанавливался так, что топ-15% постов считаются вирусными
- **p90**: Порог устанавливается так, что топ-10% постов считаются вирусными

**Результат:** Более строгий критерий виральности, более высокие пороги

## 🎯 Результаты для тестовых групп

### bez_cenznn (активная группа, ~17 постов/день)

| Метрика | p85 | p90 | Изменение |
|---------|-----|-----|-----------|
| **Порог** | 29,836 | 33,050 | +10.8% ⬆️ |
| **Вирусных постов** | 16 (13.7%) | 12 (10.3%) | -25% |
| **Постов проанализировано** | 117 (7 дней) | 117 (7 дней) | - |

## 💡 Обоснование

### Почему p90 вместо p85?

1. **Запрос пользователя**: Для группы bez_cenznn желаемый порог ~33k
2. **p85 давал**: 29,836 (слишком низко)
3. **p90 даёт**: 33,050 ✅ (идеально)

### Влияние на другие группы:

- Для **активных групп** (как bez_cenznn): изменение умеренное (+10-11%)
- Для **менее активных групп**: также +10-11%, сохраняется пропорциональность
- **Баланс виральности**: 10-12% вирусных постов - оптимальный диапазон
