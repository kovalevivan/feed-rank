# VK Views Experiment

Отдельный экспериментальный сервис для сбора данных о просмотрах постов ВКонтакте.

## Описание

Этот сервис собирает данные о том, как меняются просмотры постов в течение времени:

1. **Краткосрочное отслеживание**: Каждые 30 минут в течение 8 часов
2. **Долгосрочное отслеживание**: Проверки через 24 и 48 часов после начала сессии
3. **CSV экспорт**: Все данные сохраняются в CSV файлы для анализа

## Установка и настройка

### 1. Установка зависимостей

Зависимости уже установлены в основном проекте, дополнительно ничего устанавливать не нужно.

### 2. Настройка токена ВК

Создайте файл `.env` в корне проекта или установите переменные окружения:

```bash
# Токен ВКонтакте для эксперимента
VK_EXPERIMENT_TOKEN=033b5ad1033b5ad1033b5ad18b000beccb0033b033b5ad16b2dd6d4b4dc1ca34cf5232a

# Группы для отслеживания
VK_EXPERIMENT_GROUPS=chp_nn
```

### 3. Использование

#### Запуск через CLI

```bash
# Перейдите в папку эксперимента
cd server/services/vk-experiment

# Тестовая проверка
node cli.js test

# Запуск эксперимента
node cli.js start

# Проверка статуса
node cli.js status

# Справка
node cli.js help
```

#### Запуск с переменными окружения

```bash
VK_EXPERIMENT_TOKEN="your_token" VK_EXPERIMENT_GROUPS="chp_nn,group2" node cli.js start
```

## Структура данных

### Краткосрочные данные (`short_term_views.csv`)

Файл содержит данные проверок каждые 30 минут:

- `session_id` - ID сессии отслеживания
- `group_name` - Название группы
- `group_id` - ID группы
- `post_id` - ID поста
- `check_time` - Время проверки
- `elapsed_minutes` - Прошедшие минуты с начала сессии
- `views` - Количество просмотров
- `likes` - Количество лайков
- `reposts` - Количество репостов
- `published_at` - Время публикации поста
- `post_text_preview` - Превью текста поста

### Долгосрочные данные (`long_term_views.csv`)

Файл содержит итоговые данные за 24 и 48 часов:

- `session_id` - ID сессии отслеживания
- `group_name` - Название группы
- `group_id` - ID группы
- `post_id` - ID поста
- `initial_views` - Изначальные просмотры
- `views_24h` - Просмотры через 24 часа
- `views_48h` - Просмотры через 48 часа
- `growth_24h` - Прирост просмотров за 24 часа
- `growth_48h` - Прирост просмотров за 48 часов
- `published_at` - Время публикации поста
- `post_text_preview` - Превью текста поста

## Конфигурация

Настройки можно изменить через переменные окружения:

- `VK_EXPERIMENT_TOKEN` - Токен ВК (обязательный)
- `VK_EXPERIMENT_GROUPS` - Группы для отслеживания (обязательный)

## Архитектура

Эксперимент работает полностью независимо от основной системы:

- Использует отдельный токен ВК
- Создает отдельные CSV файлы
- Не взаимодействует с основной базой данных
- Имеет собственную систему планирования задач

## Логика работы

1. **Запуск сессии**: Собирает начальные данные по всем группам
2. **Краткосрочное отслеживание**: 16 проверок каждые 30 минут (8 часов)
3. **Планирование долгосрочных проверок**: Через 24 и 48 часов
4. **Автоматический запуск новых сессий**: Каждые 12 часов

## Файлы данных

Все данные сохраняются в папку `server/services/vk-experiment/data/`:

- `short_term_views.csv` - Краткосрочное отслеживание
- `long_term_views.csv` - Долгосрочное отслеживание

## Безопасность

- Используйте отдельный токен ВК только для эксперимента
- Токен имеет только права на чтение публичных данных
- Данные сохраняются локально в CSV файлах
- Никакие данные не отправляются во внешние сервисы

## Устранение проблем

### Ошибка авторизации ВК

```
❌ VK API Authentication Error
```

Проверьте правильность токена и его права доступа.

### Группа не найдена

```
❌ Group "group_name" not found or not accessible
```

Убедитесь, что группа существует и является публичной.

### Недостаточно прав

```
❌ Access denied
```

Токен должен иметь права на чтение стены сообществ.
