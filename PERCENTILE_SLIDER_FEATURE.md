# Интуитивный интерфейс управления количеством постов

## 📅 Дата: 12 октября 2025

### 🎯 Концепция

Заменили техническую настройку "порог виральности" на **интуитивный ползунок**, который показывает SMM-менеджеру понятную информацию: **сколько постов в неделю** будет присылаться из источника.

---

## 🎨 Новый интерфейс

### Ползунок с понятными метками

Вместо сложных перцентилей (p85, p90...) пользователь видит:

| Позиция | Метка | Перцентиль | Описание |
|---------|-------|------------|----------|
| Слева | **Больше** | p50-60 | Максимум постов (~50% всех постов) |
| ← | **Много постов** | p60-75 | Большой объём контента |
| Середина | **Средне** | p75-85 | Сбалансированное количество |
| → | **Выборочно** | p85-92 | Только успешные посты |
| Справа | **Меньше** | p92-97 | Только лучшее (~3-8% топ постов) |

### Информация в реальном времени

Пользователь видит:
- **~X постов в неделю** — главная метрика
- **Порог виральности** (в просмотрах) — для продвинутых
- **Топ постов: Y%** — процент от всех постов
- **Сравнение с текущим** — "больше/меньше чем сейчас"

## 🔧 Техническая реализация

### 1. Backend API

#### Новый endpoint: `GET /api/vk-sources/:id/percentile-stats`

Возвращает статистику для построения ползунка:

```json
{
  "available": true,
  "groupName": "bez_cenznn",
  "postsAnalyzed": 117,
  "daysAnalyzed": 7,
  "currentPercentile": 90,
  "currentThreshold": 33050,
  "averageViews": 15864,
  "medianViews": 12935,
  "percentiles": [
    {
      "percentile": 50,
      "threshold": 12935,
      "viralCount": 59,
      "viralPercent": 50.4,
      "postsPerWeek": 59
    },
    {
      "percentile": 85,
      "threshold": 29836,
      "viralCount": 16,
      "viralPercent": 13.7,
      "postsPerWeek": 16
    },
    {
      "percentile": 90,
      "threshold": 33050,
      "viralCount": 12,
      "viralPercent": 10.3,
      "postsPerWeek": 12
    },
    // ... другие перцентили
  ]
}
```

**Логика расчёта:**
- Использует `fetchPostsInTimeWindow(groupId, 7, 30, 200)` — посты за 7 дней
- Для каждого перцентиля (50, 60, 70, 75, 80, 85, 90, 92, 94, 95, 97):
  - Рассчитывает порог виральности
  - Считает количество вирусных постов
  - Оценивает `postsPerWeek = (viralCount / 7) * 7`

### 2. Frontend Component

#### `PercentileSlider.js`

**Основные возможности:**
- ✅ Загружает статистику через API
- ✅ Отображает Material-UI Slider (50-97)
- ✅ Интерполирует данные между известными перцентилями
- ✅ Показывает понятные метки вместо чисел
- ✅ Сравнивает с текущим значением
- ✅ Обновляет данные в реальном времени

**Интерполяция:**
Для значений между известными перцентилями (например, p83) используется линейная интерполяция:

```javascript
const ratio = (83 - 80) / (85 - 80);
const threshold = threshold_p80 + (threshold_p85 - threshold_p80) * ratio;
```

### 3. Database Model

Добавлено поле `customPercentile` в `VkSource`:

```javascript
customPercentile: {
  type: Number,
  default: 90,        // Default: 90th percentile (top 10%)
  min: 50,            // Minimum: 50th percentile (top 50%)
  max: 99             // Maximum: 99th percentile (top 1%)
}
```

### 4. Auto-recalculation

При сохранении нового перцентиля:

```javascript
// server/controllers/vkSources.js
if (customPercentile !== undefined && customPercentile !== source.customPercentile) {
  source.customPercentile = customPercentile;
  
  if (source.thresholdType === 'auto' && source.thresholdMethod === 'percentile') {
    // Автоматически пересчитываем порог
    vkService.updateSourceThreshold(source._id, 'percentile').catch(err => {
      console.error(`Error recalculating threshold:`, err);
    });
  }
}
```

### 5. VK Service Integration

Обновлена функция `updateSourceThreshold`:

```javascript
// server/services/vk/index.js
const percentile = param || source.customPercentile || 90;
calculatedThreshold = calculatePercentileThreshold(posts, percentile);
```

## 🎨 UX/UI детали

### Цветовая схема меток

```javascript
const getPercentileColor = (percentile) => {
  if (percentile <= 60) return 'error';    // Красный - много
  if (percentile <= 75) return 'warning';  // Оранжевый
  if (percentile <= 85) return 'info';     // Голубой
  if (percentile <= 92) return 'success';  // Зелёный
  return 'primary';                        // Синий - мало
};
```

### Адаптивность

- **Мобильные устройства:** ползунок растягивается на всю ширину
- **Desktop:** оптимальная ширина с отступами
- **Тёмная тема:** автоматическая поддержка Material-UI

### Feedback для пользователя

3. **No data state:** информационное сообщение
4. **Change indicator:** 
   - 🔼 Больше постов (красный)
   - 🔽 Меньше постов (синий)

## ✅ Преимущества нового интерфейса

### Для SMM-менеджера:
1. ✅ **Понятно:** "~12 постов в неделю" вместо "p90 = 33,050 просмотров"

4. ✅ **Предсказуемо:** Показывает реальные данные группы

1. ✅ **Точно:** Основано на реальных данных за 7 дней
2. ✅ **Гибко:** 11 точек данных (p50-p97)
3. ✅ **Автоматически:** Пересчитывается при изменении
4. ✅ **Масштабируемо:** Работает для групп любого размера
