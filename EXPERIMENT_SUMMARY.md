# ✅ VK Views Experiment - Готово к использованию!

Создан отдельный экспериментальный сервис для исследования динамики просмотров постов ВКонтакте.

## 🚀 Быстрый старт (5 минут интервалы)

```bash
cd /Users/ivankovalev/Documents/sandbox/feedrank2

# Быстрый тест работоспособности
node server/test-vk-experiment.js

# Запуск в тестовом режиме (5 мин интервалы, 30 мин общее время)
node server/run-vk-experiment.js start-test
```

## 📊 Что сделано

✅ **Отдельный сервис** - полностью изолирован от основной системы  
✅ **Тестовый режим** - интервалы 5 минут для быстрой проверки  
✅ **Автоматический сбор данных** - каждые 5/30 минут в зависимости от режима  
✅ **CSV экспорт** - данные сохраняются в удобном формате  
✅ **Долгосрочное отслеживание** - через 24 и 48 часов  
✅ **CLI интерфейс** - удобное управление через командную строку  
✅ **Группа chp_nn** - уже настроена для тестирования  
✅ **Тестовый токен** - встроен для немедленного использования  

## 🎯 Особенности

- **Тестовый режим**: 6 проверок каждые 5 минут (30 минут общее время)
- **Продакшн режим**: 16 проверок каждые 30 минут (8 часов общее время)  
- **Автоматические сессии**: новая сессия каждые 10 минут (тест) / 12 часов (продакшн)
- **Отдельный токен**: не влияет на основную систему

## 📁 Файлы данных

Данные сохраняются в:
- `server/services/vk-experiment/data/short_term_views.csv` - краткосрочные данные
- `server/services/vk-experiment/data/long_term_views.csv` - данные через 24/48 часов

## 🔧 Команды

```bash
# Тест подключения
node server/test-vk-experiment.js

# Тестовый режим (5 мин интервалы) - РЕКОМЕНДУЕТСЯ ДЛЯ НАЧАЛА
node server/run-vk-experiment.js start-test

# Быстрый тест (30 минут)
node server/test-vk-experiment-quick.js

# Полный режим (8 часов)
node server/run-vk-experiment.js start

# Статус
node server/run-vk-experiment.js status

# Остановка
Ctrl+C или node server/run-vk-experiment.js stop
```

## ⚙️ Настройка для других групп

Отредактируйте `.env` файл:
```env
VK_EXPERIMENT_GROUPS=group1,group2,group3
```
